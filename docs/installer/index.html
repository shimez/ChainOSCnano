ChainOSCnano

M5NanoC6へファームウェアをブラウザーからインストールできます。

Stable version 0.7.0

個人開発の非公式プロジェクトであり、M5Stack Technology Co., Ltd.の公式製品ではありません。

Web Installer

M5NanoC6をデータ通信対応USBケーブルでPCへ接続し、下のボタンからシリアルポートを選択してください。

このブラウザーはWeb Serialに対応していません。デスクトップ版ChromeまたはEdgeを使用してください。
  1. データ通信対応USBケーブルでM5NanoC6をPCへ接続します。
  2. 「Install ChainOSCnano」を押してシリアルポートを選びます。
  3. 画面の案内に従ってインストールします。
ポートが表示されない場合は、本体ボタンを押しながらUSBを接続してダウンロードモードを試してください。
再インストールや消去を行う前に、必要な設定をWeb UIからJSONへバックアップしてください。

Quick Installation Guide (English)

Use desktop Chrome or Edge. Connect the M5NanoC6 with a USB data cable, select Install ChainOSCnano, choose its serial port, and follow the instructions.

If the port is missing, hold the built-in button while reconnecting USB to try download mode. Back up important settings as JSON before reinstalling or erasing.
